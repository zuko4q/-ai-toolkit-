# AI Toolkit 🤖

A practical collection of small, reusable AI utilities for experiments, automation, and developer workflows.

## Planned modules

- 🧠 Prompt and model utilities
- 🔎 Text extraction and transformation helpers
- 🗂️ Structured data processing
- ⚙️ Automation-friendly command-line tools
- 🧪 Tests and examples for every useful component

## Project status

🚧 Initial build — modules will be added incrementally.

## Design goals

Keep the toolkit modular, understandable, dependency-conscious, and safe to run locally. Secrets and credentials should always come from environment variables rather than source control.
